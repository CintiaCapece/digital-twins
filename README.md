# Digital Twins

Página educativa en español sobre gemelos digitales para redes autónomas, con demos locales IP/MPLS y factibilidad de uplink.

🌐 **[Ver la página y probar las demos en GitHub Pages](https://cintiacapece.github.io/digital-twins/)**

Sitio estático sin dependencias. Abrir index.html en un navegador. Los escenarios utilizan datos sintéticos y no controlan infraestructura real.
